## 9. Gate decision

- `PASS` — письменные условия закрывают все обязательные поля Gate 0.
- `CONDITIONAL` — модель пригодна только при перечисленных ограничениях.
- `HOLD` — ключевые поля не подтверждены.
- `REJECT` — источник/партнёрская дистрибуция запрещены либо экономика/статусы непрозрачны.

### Обязательные блокеры

- [ ] собственный или co-branded путь разрешён;
- [ ] профессиональные distribution partners/субагенты допустимы;
- [ ] target action однозначен;
- [ ] dedup известен;
- [ ] hold и платёжный календарь известны;
- [ ] статусы и сверка доступны;
- [ ] порядок ПД и согласий понятен;
- [ ] ответственность за рекламу/ЕРИР распределена;
- [ ] pipeline после расторжения защищён;
- [ ] экономика оставляет устойчивую маржу после выплаты партнёру.
